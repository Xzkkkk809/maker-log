# 西南交通大学从代码到实物课程

#### 介绍
西南交大从代码到实物课程作业合集，用于整合课程作业，包括完整代码，实现日志，硬件说明，
方便课程学习

#### 软件架构
采用[总仓库+分项目文件夹]的结构：
-根目录：总仓库README，作为所有作业的检索入口
-单个项目文件夹：按'周数+作业名称'命名，进行物理隔离
-项目内固定结构：'code/'（存代码）,'doc/'(存日志/接线图),'README.md'（项目说明）


#### 安装教程

1.  克隆仓库到本地：'git clone 仓库地址'
2.  进入对应文件夹，查看'README.md'获取硬件接线与使用说明
3.  打开'code/'文件夹内的'.ino'文件夹，在Arduino IDE中编译烧录到开发板

#### 使用说明

1.  总仓库根目录的「作业目录」可快速定位对应课程作业
2.  单个项目文件夹内：
    - `code/`：存放项目完整可编译代码
    - `doc/`：存放项目详细实现日志、硬件接线图、问题解决记录
    - `README.md`：项目快速说明，包含硬件清单、核心功能、接线方式
3.  所有代码均在Arduino IDE 2.x版本、ESP32开发环境下测试通过
