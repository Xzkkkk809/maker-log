Git 学习与实践

版本控制，云端备份，项目管理的核心工具

一、什么是 Git

Git 是目前世界上最先进、最流行的分布式版本控制系统，由 Linux 之父 Linus Torvalds 为管理 Linux 内核开发而创建。 简单来说，Git 可以帮你记录文件的每一次修改历史，方便回溯旧版本、对比差异，同时支持多人协作开发，是程序员与创客必备的工具。

对于创客项目而言，Git 可以管理代码、设计图纸、文档日志等所有文件，让你不用担心“修改坏了无法还原”，也能清晰看到项目的成长轨迹。

二、Git 核心概念

  • 仓库（Repository）：存放项目所有文件和修改历史的地方，分为本地仓库（你电脑上的文件夹）和远程仓库（如 Gitee/GitHub 上的托管仓库）。
  • 提交（Commit）：将文件的修改保存到本地仓库的操作，每一次提交都会生成一个唯一的 ID（哈希值），相当于给项目拍了一张“快照”。
  • 分支（Branch）：从主线上分离出来的独立开发线，可以在不影响主线（main/master）的情况下开发新功能，完成后再合并回去。
  • 远程仓库（Remote）：托管在网络服务器上的仓库，用于备份代码和多人协作，本课程使用 Gitee 作为远程仓库平台。

仓库结构说明

仓库采用「总仓库 + 分项目文件夹」的架构，方便管理和检索：

  • 根目录：总仓库 README.md，作为所有作业的检索入口；
  • 项目文件夹：按 周数+作业名称 命名（如 week6-LED&sg90），实现物理隔离；
  • 项目内固定结构：
    • code/：存放项目完整可编译代码；
    • doc/：存放项目详细实现日志、硬件接线图、问题解决记录；
    • README.md：项目快速说明，包含硬件清单、核心功能、接线方式。

四、Git 基础操作流程（结合本仓库）

1. 克隆远程仓库到本地

首次使用时，需要将 Gitee 上的远程仓库克隆到你的电脑上： 

git clone https://gitee.com/xzk-creator/xxxxxxzzk.git

2. 配置用户信息（首次使用必做）

配置你的用户名和邮箱，用于标识提交者： 

git config --global user.name "xzk-creator"
git config --global user.email "你的邮箱@example.com"

3. 日常更新与提交流程

每次完成作业或修改文件后，按照以下步骤将代码同步到远程仓库： 

# 1. 查看当前文件状态
git status

# 2. 添加所有修改过的文件到暂存区（或者指定文件名）
git add .

# 3. 提交到本地仓库，写清楚提交信息
git commit -m "提交说明：例如完成 week6 LED与SG90舵机控制"

# 4. 推送到 Gitee 远程仓库
git push

💡 提示： 建议养成“小步提交”的习惯，每完成一个小功能就提交一次，方便后续回溯和定位问题。

4. 拉取远程更新

如果在多台电脑上工作，或者远程仓库有更新，先拉取再修改： 

git pull

五、Git 在创客项目中的价值

  • 版本回溯：不用担心改坏代码，随时可以回退到任意一个历史提交版本；
  • 过程记录：完整的提交日志就是你的项目成长日记，清晰看到从想法到实现的全过程；
  • 云端备份：推送到 Gitee 后，代码和文档有了云端备份，不怕电脑故障丢失文件；
  • 团队协作：如果是团队项目，Git 的分支管理和合并功能可以高效支持多人协作开发。
