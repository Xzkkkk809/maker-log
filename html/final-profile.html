// 01 · Project Profile

项目简介 & 团队介绍

从一个真实痛点出发，经过多次迭代优化，到一款集语音提醒、防作弊判定、喝水次数记录于一体的智能杯垫。

项目概览 / Overview
项目名称
干杯！专注饮水提醒杯垫
小组名称
干杯小队
目标用户
图书馆/自习室长时间学习的大学生
核心场景
专注自习时无意识忽略饮水需求
制作周期
2 天
最终版本亮点
语音提醒 + 防作弊判定 + 喝水次数记录
设计挑战 / HMW
"我们如何能够让长时间专注学习的学生，更容易注意到自己该喝水了？"
超过一定时间未喝水 无明显提醒机制 影响健康和专注力 传统方法依赖主动记忆
最终系统逻辑 / System Logic
模块说明
输入感知杯垫内轻触开关（× 3 并联）：杯在 → LOW，杯走 → HIGH
待机状态绿灯常亮；每次放下水杯，绿灯闪烁次数 = 今日已喝水次数
轻度提醒超过 8 秒未拿起：红绿灯交替闪烁 + ASR01 语音播报"喝水吧"
强烈提醒再过 4 秒仍未拿起：纯红灯持续闪烁
防作弊判定拿起水杯后必须超过 3 秒再放回才算有效；3 秒内放回视为无效，红灯继续
语音模块ASR01 通过串口与 ESP32-S2 交互，外接喇叭播报语音提醒
演示模式计时阈值缩短，现场实时演示完整流程
