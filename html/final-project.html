⚙️ Tech Stack & Code

硬件清单：

  • ESP32 s2 mini
  • 杜邦线
  • 红，绿LED灯
  • 电阻
  • 面包板

核心代码：

const int redLED = 2;
const int greenLED = 9;
const int button = 5;

unsigned long pressTime = 0;

void setup() {
  pinMode(redLED, OUTPUT);
  pinMode(greenLED, OUTPUT);
  pinMode(button, INPUT_PULLUP);
  
  // 开机绿灯亮
  digitalWrite(redLED, LOW);
  digitalWrite(greenLED, HIGH);
}

void loop() {
  // 按钮按下
  if (digitalRead(button) == LOW) {
    if (pressTime == 0) {
      pressTime = millis();
    }

    // 按满3秒 → 红灯亮
    if (millis() - pressTime >= 3000) {
      digitalWrite(redLED, HIGH);
      digitalWrite(greenLED, LOW);
    }
  } 
  // 按钮松开 → 立刻回到绿灯
  else {
    pressTime = 0;
    digitalWrite(redLED, LOW);
    digitalWrite(greenLED, HIGH);
  }
}

🧠 Reflections

遇到问题：蜂鸣器无法正常工作，且风险极大，烧坏3块电路板

原因分析：接线错误 + 程序逻辑不完善

解决方法：放弃蜂鸣器，改用红绿LED灯作为提醒装置

经验总结：硬件与软件必须同步调试，逐步排查问题
